## Resonance 1.1.0

- English and Italian UI, with an in-app language selector and saved preference.
- Removed the “Downloaded files” sidebar item.
- Automatic daily update checks and a manual “Check for Updates…” command. Installation always asks for confirmation.
- Signed Sparkle updates delivered through GitHub Releases; running downloads delay the restart.
- Smaller, reproducible FFmpeg builds and a compact QuickJS-ng runtime in place of Deno.
- GPL-3.0-or-later source, pinned dependencies, native build scripts, CI and release automation.

macOS 13 or later, Intel and Apple Silicon. All runtime components are included.

This initial public release is signed ad hoc, not with Apple Developer ID, and is not notarized. Gatekeeper may require explicit approval in System Settings → Privacy & Security. Do not disable system protection globally. Sparkle update signatures still verify the origin and integrity of update files.

Spotify supplies public metadata; matching audio comes from YouTube and may be a different recording. Public Spotify previews may contain only part of a playlist. Only download content you own or are authorized to download.
